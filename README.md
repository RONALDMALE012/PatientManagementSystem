 Patient Management System
 Description

A web-based Patient Management System developed using Python Django and MySQL.

 Features

- User Authentication
- Dashboard Analytics
- Patient Management
- Appointment Management
- Visit Management
- Reports
- PDF Export
- Excel Export

 Technologies
- Python
- Django
- MySQL
- Bootstrap 5
- HTML
- CSS
- JavaScript

 Installation

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
